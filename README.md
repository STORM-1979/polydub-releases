# PolyDub Releases

Public binary releases of [PolyDub](https://github.com/STORM-1979/polydub) (source code in private repo).

This repo hosts:
- `PolyDub_Setup_v*_Lite.exe` — Windows installer
- `cuda_pack_v*.zip` — optional GPU acceleration pack
- `cuda_pack_v*.sha256` — checksum

See [Releases](https://github.com/STORM-1979/polydub-releases/releases) tab.
